# 浮生 · 青溪镇的人生记事

## LOL 上路对线实验室

本仓库另有独立的 `lol_sim`：面向 PC 正式服 26.18 的上路 1–6 级可复现模拟器，包含盖伦、德莱厄斯、贾克斯、墨菲特的技能加点、符文、召唤师、出门装、兵线和策略搜索。它使用 8767 端口，不影响下面人生游戏的 8766 端口。启动方式、配置 schema、模型边界和代表性对位报告见 [docs/lol-top-lab.md](docs/lol-top-lab.md)。

```powershell
python -X utf8 -m lol_sim serve --port 8767
```

**v0.5：在独立演化的架空时代中，与跨世代的人群相识，经历有生存压力、长期关系与人物志的一生。**

在虚构的青溪镇出生，经历约 30 次关键人生选择及途中出现的休整机会，学习、谋生、与人相遇。选择会改变资源、关系和未来事件；结局把真实经历整理成人物志，每条观察都可以回看对应的事件。

## 开始游戏

需要 Python 3.10 或更高版本。使用标准库，无需安装依赖、模型密钥或联网生成内容。

在项目根目录运行：

```powershell
python -X utf8 -m game.server --port 8766
```

随后在浏览器打开 **http://127.0.0.1:8766**。Windows 也可以双击项目内的 `启动游戏.cmd`，保留该命令窗口，再打开上述地址。

若端口已被占用，可将命令中的 `8766` 改为其他空闲端口，然后打开相应地址。服务仅监听本机，没有发布到公网。

## 现在可以玩什么

- 从出生记录开始，6 岁起进行选择，经历童年、少年、青年、中年和晚年，直至健康耗尽或 82 岁终章。
- 三种家庭起点，125 个个人事件、375 个选项，以及 120 个自主发生的宏观事件；每局约 30 个关键选择位置，关系答复、借款到期与休整机会可额外插入。
- 20 个世界领域覆盖经济、劳动、住房、教育、卫生、人口、文化、信息、治理、权利、贸易、战争与和平、能源、食物、基建、生态、气候、灾害、技术与太空前沿。
- 新人生诞生于新历元年。世界事件读取当时状态、前提与冷却条件，推动四组发展模式和 20 项指标；没有按现实年份排列的必然历史。
- 60 个社会响应事件将时代变化转化为个人、家庭和社区的具体选择，宏观环境也影响成年后的常规收入和生活开支。
- 学习、职业、住房、亲属照护、友谊、婚恋、子女、退休和回顾等条件事件；单身与无子女路线也能完整结束。
- 现金、精力、健康、压力、学识与技能；成年后逐年结算收入和生活支出，援助有额度，缺口有后果。
- 稳健、加紧、放慢三种节奏；下一年预算与精力/压力预估；跨年危险时先安排一次休整机会。
- 新增早年手艺、学习、互助、住房与晚年关系的后续事件，可以回看触发它们的实际选择。
- NPC 有自己的年龄、生死、现金与亲近状态。死亡后终止本人参与的计划，保留关系与未清偿债务。
- 新增跨世代 2,000 人容量、200 位详细模拟人物与最多 200 人的关注名单；实际相識、直接交往、当前密切与曾经密切分别计数。
- 128 种职业与生活阶段、32 种处境、12 个 NPC 性格轴和 12 类动机；职业不决定善恶。32 类 NPC 双人互动包含互助、合作、欺骗、剥削、侵占、伤害及修复，相关后续绑定同一对当事人。
- “人间来往”支持已知人物搜索、筛选、档案、消息、主动交往与年度安排。重要人物保留模拟开始后的实际时间线，页面只显示玩家已经获知的部分。
- 像素小城场景、人物档案、可筛选年表，以及带经历链接的人物志。新增“时代纪事”，按领域、尺度或关键词查看已经发生的世界变化并导出。
- 当前浏览器自动保存，支持导入/导出 JSON 存档，以及导出 Markdown 人物志。

## 保存进度

每次选择成功后保存到当前浏览器的 IndexedDB 数据库，以容纳增长中的人群记录；不可用时尝试本地存储。重新打开同一地址会接续存档。清理浏览器数据、使用另一个浏览器或改变端口，会影响这份自动存档的可用性；可先在右上角菜单中导出。

导入存档时会检查版本、状态、时间、NPC、当前事件和世界历史的一致性。v0.2、v0.3、v0.4 存档可迁移至 v0.5，已经发生的历史、原有年份与当前事件保持原样。新增人群从迁移所在年开始记录，不补写过去的交往。浏览器保留旧版自动存档并提供升级前备份导出；其他未知版本暂不自动迁移。当前格式为 1.3.0，是包含隐藏世界事实的可编辑单机存档，不提供防作弊能力。

## 本版的明确边界

- 这是小城人生与抽象宏观世界结合的可玩原型。事件库提供可扩展的覆盖框架，没有穷尽现实中的任何情况；指标、经济、NPC 行为与寿命均经过简化，82 岁是本版的叙事终点。
- 目前内容在开发阶段整理，运行时不调用大模型。还没有批量生成、审核和发布资产的平台。
- 画像描述本局角色的可观察选择，采用八个工作维度及三层子维度；报告增加有效机会、独立剧情、行为/情境分布、压力与关系范围、反例和限制说明。不输出人格分数，也不测量现实玩家的人格。
- 结局文字由程序按真实记录组织。NPC 关系网每人最多六条人物关系边，完整家庭谱系、组织与制度、空间移动、疾病、法律和全球社会尚未全面模拟；128 个职业标签也没有完整的资格与权限系统。
- 2,000 是跨世代档案容量，200 是详细模拟与关注层的规模，不能当作每局实际认识 2,000 人、同时密切相处 200 人的保证；实际覆盖见本版人口报告。外围人物保留最近六条记事，提升关注后不会补造遗失的过去。
- 像素画由本地 Canvas 代码绘制，中文正文优先保证可读性。
- 平衡仍需真实试玩反馈；`reports/balance-v0.3.md` 是上一版的历史报告，不能作为本版平衡结论或玩家表现预测。
