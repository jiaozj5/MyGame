# 项目状态：浮生 · 青溪镇的人生记事（v0.6 工作状态）

更新时间：2026-09-19

## 总结

当前项目已经是一个可以本地运行、从出生推进到晚年并生成个人物志的可玩原型。核心规则、事件、世界推进、NPC 人群、存档迁移和人物画像评价已经接通，并有自动化测试和内容静态检查支撑。

项目仍然处于内容和系统原型阶段。它没有覆盖现实世界的所有可能事件，也没有在运行时调用大模型来持续生成世界；当前的资产由 JSON 内容库和确定性的规则驱动。

## 已完成

### 1. 可玩的人生主循环

- 本地 HTTP 游戏服务，默认端口 `8766`。
- 从出生记录开始，6 岁起进行关键选择，推进到健康耗尽或 82 岁终章。
- 三种家庭起点、约 30 个关键选择位置，以及可插入的关系答复、借款到期和休整机会。
- 现金、精力、健康、压力、学识、技能等生存资源；成年后有收入和生活支出结算。
- 稳健、加紧、放慢三种推进节奏，并在跨年危险时提供休整机会。
- 事件选择、条件触发、资源消耗、关系变化、世界影响和存档均由同一套规则处理。

### 2. 事件库与架空世界

- 65 个个人经历事件、60 个社会与环境响应事件、120 个宏观世界事件。
- 宏观事件覆盖 20 个领域，包括经济、劳动、住房、教育、卫生、人口、治理、权利、贸易、战争与和平、能源、食物、基建、生态、气候、灾害、技术和太空前沿等。
- 世界使用新历元和独立随机流；事件根据状态、前提和冷却条件触发，不按现实年份重放既有历史。
- 社会响应事件把时代变化转化为个人、家庭和社区层面的选择。
- 事件已经加入年龄阶段、压力、关系范围、事件尺度、信息可得性、时间跨度、事件组和观察子维度等评价元数据。
- 内容检查会校验事件结构、条件、引用、评价维度和覆盖矩阵。目前报告为 `125 events; 0 errors; 0 warnings`。

### 3. NPC 与人群模拟

- 2,000 人跨世代档案容量，最多 200 人进入详细模拟和关注层。
- NPC 具备年龄、生死、现金、职业、处境、性格轴、动机、关系和自身时间线。
- 已实现出生、死亡、职业变化、有向关系、案件后续、限期释放，以及玩家知识和私密事实的分离。
- 128 种职业与生活阶段、32 种处境、12 个性格轴、12 类动机和 32 类双人互动。
- 互动包含互助、合作、欺骗、剥削、侵占、伤害和修复；互动后续绑定同一对当事人，并避免死亡 NPC 在后续事件中重新出现。
- “人间来往”页面支持搜索、筛选、档案、消息、主动交往和年度安排；页面只显示玩家已知信息。
- 已完成批量人口报告和存档往返验证，报告记录关系数量、运行时间、存档大小和确定性复跑结果。

### 4. 人物画像评价体系

- 采用 8 个工作维度，每个维度有 3 个子维度，共 24 个行为观察入口。
- 画像只总结本局角色在具体事件中的可观察行为，不输出 MBTI 类型、心理测量分数、概率或对现实玩家的诊断。
- 画像会记录有效机会、独立剧情、行为和情境分布、压力范围、关系范围、信息条件、时间跨度、反例、证据等级和限制说明。
- 同一事件组只作为独立剧情计数一次，避免重复选项把证据权重虚高。
- 已建立 `content/personality-coverage.json` 覆盖矩阵，并由 `game/personality_report.py` 生成可审计的 JSON 和 Markdown 报告。
- 当前覆盖报告统计 125 个事件，8 个维度均有至少 4 个事件入口；当前仍是“未做心理测量学验证的情境行为画像”。

### 5. 前端、存档和导出

- 2D 像素风 Canvas 场景和中文界面。
- 人生、人物、时代纪事、年表和人物志页面。
- 浏览器 IndexedDB 自动保存，本地存储作为回退；支持 JSON 存档导入/导出和 Markdown 人物志导出。
- 已实现 v0.2、v0.3、v0.4 存档迁移到 v0.5，并检查时间、NPC、当前事件和世界历史的一致性。
- 人物志页面显示画像指标、子维度、行为面、压力、关系、信息条件和限制说明。

## 部分完成，仍需打磨

### 内容质量

- 事件元数据已经覆盖并能被程序校验，但一部分年龄阶段、压力和信息条件仍使用 `multi_stage` 或较宽泛的标签，需要逐事件进行编辑审阅。
- 事件库提供可扩展的覆盖框架，不等于现实世界全部场景；各维度在不同年龄、资源压力、关系尺度和信息条件下的平衡仍需补充。
- 事件文本、选项代价、获得值和后果需要持续进行数值平衡与真实试玩校准。

### 人物画像

- 当前画像是结构化行为证据汇总，还没有真实玩家样本、重测信度、效度或跨文化校准。
- 画像已经统计机会和情境分布，但尚未实现每个维度的动态机会权重、反事实选择分析和跨多局聚合。
- NPC 关系事件已记录关系结果，但关系网络对画像的独立证据仍然有限。

### NPC 与世界

- 2,000 是容量和档案规模，200 是详细模拟上限；它不代表每局会自然认识 2,000 人或同时维持 200 段深度关系。
- 重点 NPC 有完整运行时间线，外围 NPC 只保留压缩记录；完整家庭谱系、组织制度、空间移动和全球社会因果还没有全部模拟。
- 职业标签已覆盖类别，但资格、权限、组织层级、劳动市场和法律制度还没有形成完整可运行系统。

### 生成与资产管理

- 运行时不调用大模型，没有批量生成、审核、版本冻结、依赖图、发布和回滚的一体化资产平台。
- 当前内容由人工维护的 JSON 和 Python 规则驱动；后续若接入大模型，需要增加 schema 校验、状态转移验证、冲突检测、人工审核队列和可复现版本锁定。

## 尚未完成的主要目标

- 建立覆盖个人、家庭、组织、国家、自然环境和未来分支的更大规模事件库，并为每类事件补齐可验证的前提、后果和评价机会。
- 建立完整的 NPC 时间线生成与世界级社会因果模拟，让玩家可见信息和隐藏世界状态长期保持一致。
- 完成关系网络、家庭谱系、组织制度、迁徙空间、疾病健康、法律程序和全球社会系统的联动模拟。

- 建立内容创作流水线：模板、生成、结构检查、语义审查、人工批准、版本管理、依赖追踪、灰度测试和回滚。
