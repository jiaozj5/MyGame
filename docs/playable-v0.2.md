# 可玩版本 v0.2

## 这次交付

本版完成一段有起点、有生活约束、有关系变化、能走到结局的完整人生。它用本地 Python 规则引擎驱动浏览器页面，没有每轮在线生成等待，也没有公网部署。

### 一、完整循环

1. 输入角色名，选择家庭起点，可以指定人生编号以复现随机过程。
2. 记录出生，从 6 岁的关键选择开始。
3. 选择前检查年龄、资源、人物、关系和经历条件；不可行选项显示具体原因。
4. 先试算选择的全部效果，验证成功后一起提交。
5. 前进到下一人生片段，途中逐年处理收支、援助、紧缩、精力、压力、衰老与 NPC 变化。
6. 关系答复、借款到期等事项可插入，不把未来计划写成已发生事实。
7. 健康耗尽或完成 82 岁终章时结束，人物志从实际记录中整理关键经历，年表保留完整记录。

主要选择年龄为 6、9、12、15、18、20、23、26、30、34、38、42、46、50、55、60、65、70、75、80、82；有些年龄有两个片段。不是每年都要求玩家点一个按钮。

### 二、生存和职业

现金、精力、健康、压力、学识与技能构成当前状态。工作收入、生活成本、学习和能力互相影响；成年前由家庭提供基本生活，成年后才承担个人年度开支。

本版职业包括零工/待业、学徒、技术工人、职员、教师、自由职业和退休。退休与支出模型是虚构规则，不对应真实地区的法律制度。经济数值以可玩性为目的，尚未经过充分平衡。

现金短缺时不会默默变成负数。亲属帮助会扣除对方实际资金，公共援助有额度；剩余缺口转为生活紧缩、健康和压力影响。

### 三、NPC 和因果

母亲许岚、父亲林川、朋友周远、后来可能相识的陈安，各有独立年龄和状态。亲近可以随交往改变，认识某人不等于已经成为伴侣。建立关系、照顾孩子、保持单身、拒绝某份工作等都通过明确选择和条件记录。

NPC 的死亡会终止需要本人继续行动的事项；借款本金和关系记忆保留。遗信事件需先有生前留信经历，不能为了补剧情临时制造一段不存在的过去。

目前 NPC 的自主性用意愿门槛、资源约束、条件回复和年度变化表达，未实现通用的自由规划智能体。

### 四、人物志

结局包含人生概述、各阶段关键经历、八类选择观察、重要关系与结语。正文精选经历，避免年度收支淹没故事；引用直接对应时间线 ID，可点击回看当时发生了什么。完整生活账与全部选择仍留在人生年表中。

选择前的资源、实际可行选项、锁定原因和支出负担进入记录。受约束的选择仍属于人生事实，但不会自动被归因为稳定人格偏好。本版证据覆盖保守标为“有限”或“未观察”，没有心理分数、准确率或现实玩家诊断。

### 五、界面

首页确定角色和家庭。游戏中有“这一刻”“牵挂的人”“人生年表”“人物志”四个页面，选择后保留上一段的结果。场景用 Canvas 绘制原创像素房屋、山丘、河流、树木和人物，不依赖下载图片。布局支持桌面双栏与窄屏单栏。

正文采用可读中文字体，像素风主要体现于场景、头像、边框和色彩。暂未加入音效与动画资产系统。

## 数据与旧版的关系

v0.2 的可执行内容是 `content/life-events.json`，规则入口是 `game/engine.py`。v0.1 的三个规则样例仍单独保留，作为设计和测试参考。

当前存档包含版本、种子与随机进度、世界状态、当前事件、已发生事件和完整时间线。导入检查结构和已建模关系；内容版本变动需要明确迁移。这里没有用于不可信多用户环境的签名、防作弊、账户或云存档。

## 验证边界

包含完整人生、多种家庭起点、资源边界、死亡债权、存档接续、人物志引用和接口测试。浏览器中检查首页、选择推进、关系档案、年表和结局。

2026-09-16 浏览器验收：普通家庭、人生编号 2026 的路线完成 32 次选择，到达 82 岁结局；实际经过借款归还、交往被拒、父母离世与生前家书回顾。人物志引用能跳转并高亮原始选择，刷新能接续进度。检查了 1280 与 390 像素宽度，无横向溢出；该次浏览器测试未发现脚本错误。测试结束后恢复正常视口。

这些检查证明已测试路径与已编码约束成立，不证明所有现实常识或全部事件组合均正确。当前数值偏宽松，难度与内容节奏需要用户试玩后继续调节。

## 继续开发的优先级

1. 通过真实试玩调整收入、压力、健康和不同职业路径，使生存压力有分量且可理解。
2. 增加更多会因早年选择改变的后续事件，减少通用日常兜底的重复。
3. 将当前单一亲近值拆成信任、亲密、承诺和冲突；为 NPC 增加更明确的目标和行动计划。
4. 建立事件编辑器、不可达条件检测、审核状态、内容版本迁移和发布流程。
5. 以玩家研究检验画像描述是否成立，再扩充逐维度机会判断和反例归纳。

先检验这个版本是否让人愿意走完一生，再扩展世界范围。
