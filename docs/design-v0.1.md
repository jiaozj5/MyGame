# 首版方案 v0.1

## 一、产品核心

玩家在有限的社会背景中经历一生，面对资源、关系和价值之间的取舍。选择改变现实处境与他人未来；结局基于实际经历生成人物志，呈现有证据的选择模式。

首版先以一个虚构小城为世界背景。性别、出生条件、家庭结构、能力和身份影响可获得的机会，但不能直接生成善恶或人格结论。所有数值与维度都是需要试玩检验的设计假设。

## 二、三套规范怎样连接

| 输入 | 产生什么 | 保存在哪里 |
| --- | --- | --- |
| 当前时代、角色、位置、关系、历史 | 可以发生的候选事件 | 世界实例 + 事件条件 |
| 事件参与者、资源和资格 | 当时真正可执行的选项 | 选择快照、锁定原因 |
| 玩家选择、明确的成本与后果 | 下一世界状态与未来计划 | 事务日志、状态快照 |
| 实际选择机会、对象、压力、负担 | 有情境限制的行为证据 | 证据记录 |
| 人生事实、行为证据与反例 | 人物志与选择画像 | 结局报告 |

完整人生中，偶然事故、他人决定、无资格参与和被迫行为都应保留在事实层；它们不能直接当作玩家的自愿人格选择。

## 三、首版的产品取舍

### 1. 时间和生存

未来可玩版按人生阶段展示关键选择，平稳期较快推进，危机期较细推进。世界时间统一记为日；年龄暂按 365 天一年计算。

早期试玩界面优先展示现金、精力、健康、压力，以及住房/食物/照护等当前生活义务。技能、详细关系、知识和历史放进档案，避免玩家每回合管理几十条数值。

当前原型只实现日时钟与显式事件成本。它没有饥饿衰减、工资、房租结算、技能成长或完整寿命模型；“花时间帮忙”的样例只结算精力，日内时间预算留待下一阶段。

### 2. 选择与性格

不会用推断的“善良”“勇敢”限制玩家能选什么。现实资格和资源可以限制行动，并在选项旁解释原因。

第一版先记录八类工作维度及其情境：探索、坚持、社交发起、关怀、公平与承诺、冲突方式、风险应对、求助。维度内允许多种行为，不规定一条由坏到好的顺序。

目前执行器记录事件作者标注的候选行为，尚未实现逐维度的有效机会判断、反例归纳和跨阶段聚合。不会把候选数量当作人格得分。

### 3. NPC 与内容

人物有不可被后续生成覆写的历史，也有可以失败或改变的计划。NPC 可以拒绝玩家提议，其结果要与能力、资源、关系和动机匹配。

当前还款样例只用一个明确的意愿字段演示 NPC 不必服从，不代表已经实现 NPC 的目标规划或协商模拟。死亡由系统测试命令触发，与借款选择没有因果关系。

### 4. 画面

未来界面采用像素场景、人物立绘或头像、事件卡、资源栏、关系档案、人生时间线。文本保持易读，像素字体可只用于标题和短标签；资源成本和锁定原因应清楚可见。

本轮没有生成视觉资产，也没有实现 UI。

## 四、已经落实的内容

### 数据与文档

- 世界规则：状态、时间、属性、关系、知识、计划与死亡。
- 事件契约：绑定条件、选项成本、动作白名单与事务。
- 画像规范：工作维度、有效观察机会、约束和输出边界。
- 12 个相互关联的人工事件草案，跨童年、青年、成年、晚年。
- 其中借款请求、债务到期、生前信件已写成 JSON 并可执行。

### 三条运行样例

1. 现金 600、住房目标 500，借出 100；到期收到整笔还款。
2. 借出 400；朋友在独立的测试事件中去世，取消需要其主动参与的还款计划，保留未处理债务，并可阅读已经存在的生前信件。
3. 现金与精力均为零，只有拒绝可执行；记录困境和选择，不输出候选画像证据。

这三条路径验证基础规则。第一条尚未模拟朋友拿借款支付账单、就业收入等经济活动，不能据此判断生存平衡或还款概率。

## 五、内容如何继续扩充

先由设计者列出缺失的经历、选择冲突和情境，再让模型生成候选。模板必须能用已有规则表达。新增继承、婚姻、工作等机制时，先实现状态和规则，再接收相关事件。

发布流程目标是：结构检查 → 跨实体与时间检查 → 批量运行 → 文本和时代审核 → 版本发布。当前只实现小型本地 JSON 目录与领域检查，其余是后续建设项。

生成质量不能只统计数量；还应查看条件不可达、同一选项长期占优、过度重复、人生阶段断档、角色状态冲突和证据误判。

## 六、下一阶段：一段真正可玩的完整人生

建议下一阶段交付一个本地可玩的版本，优先完成：

1. 出生、成长、成年、老年和死亡的完整流程；日常义务与关键事件分开推进。
2. 将住房、生活开销、工作和恢复变成明确规则，避免只展示压力而不实际结算。
3. 将精选事件草案转成可执行资产，加入基础冷却与叙事阶段，支持必要的日常兜底。
4. 做选择卡、锁定原因、资源、NPC 档案和时间线的最小界面。
5. 输出可点击回看证据的人物志；充分评估后再做维度聚合。

完成标准：玩家能从开始走到结局；至少一段重要关系被多次选择改变；生存约束有后果；所有关键结论有实际事件依据；核心回合不依赖在线模型返回。

之后再扩充地区和年代、建设内容工作台，以及尝试后台生成。尚未决定最终引擎、发行平台、单局时长和商业化方式；这些不影响本轮底层规范。

## 七、验证边界

测试覆盖资金守恒、即时成本、整笔清偿、死亡取消、反向关系、到期前提失效、NPC 意愿、锁定选项、旧候选重复提交、信件知识时间和回放完整性，以及 300 条短随机路径。

通过这些测试说明给定样例与已测试规则边界成立；不证明所有现实常识、所有资产或完整人生都没有矛盾。自由文本的全部语义、时代真实性、心理测量效度和游戏乐趣仍需要单独验证。
