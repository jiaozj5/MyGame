# v0.4 社会变化中的个人事件

## 内容范围

`content/society-events.json` 包含 60 个独立事件、180 个选项。20 个宏观领域各提供个人、家庭、社区三种生活层面的响应。事件读取世界状态，但其行动只改变角色资源、与已存在 NPC 的关系及个人经历标记。

## 触发与效果契约

- 文件及每个事件的版本为 `0.4.0`；事件 ID 为 `society.<domain>.<scope>`，`scope` 为 `personal`、`family` 或 `community`。
- 每个事件至少读取一个 `world.metrics.*` 数值门槛或 `world.modes.*` 模式。没有固定年份条件；年龄仅用于判断角色是否适合遇到该情境。
- 数值门槛决定是否具备触发资格，不保证该事件必然出现。目录设计不等于已经证明所有路径可达。
- 每个选项使用现有个人事件操作码，不修改世界指标或模式，不让一次地方活动替国家决策。
- 金钱、精力等明确支出均有对应选项门槛。每个事件至少有一项在现金与精力均为零时可执行；该项仍可能带来压力、延后安排或有限的信息收益。
- 选项顺序轮换，不能把固定位置当作优劣等级。不同方案在金钱、精力、隐私、关系、即时完成与等待之间取舍。
- 个人经历写入 `society_<domain>_<scope>_response`，值为实际选择 ID。该标记不表示宏观问题已经解决。

## 人物与叙事边界

家人和朋友使用已有的 `mother`、`father`、`friend`、`partner`。作为在场参与者时，均要求 `alive=true`、`met=true`；共同伴侣生活另外要求 `flags.partnered=true`。不创建假定已经存在的孩子或新的持久 NPC。窗口人员、来访者、居民等只作为当场的匿名人物。

内容写玩家能够看见的小范围结果：完成一次练习、明确一项分工、提供一批物品、确认一条路线。尚待他人回应的事项不自动写成获批。世界是虚构的澄川、新历，不对应现实地区的法律程序、医疗规范或历史事件。

八维观察沿用 `personality-dimensions.json`，记录具体行动，不给选项贴善恶分数。锁定选项仍是约束，不能将“付不起钱”解释为“不愿关心”。

## 验证

运行：

```powershell
python -X utf8 -m unittest discover -s tests -p test_society_content.py -v
python -X utf8 -m game.content_check --catalog content/society-events.json --json
```

局部测试覆盖：20×3 内容合同、真实世界门槛、零现金零精力下的可执行方案、NPC 生死与相识前置、个人操作不改写世界。完整世界轨迹中的触发频率、事件之间的节奏和长期数值平衡，需要结合引擎整体试玩另行观察。
