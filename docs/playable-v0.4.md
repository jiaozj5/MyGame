# v0.4：事件库与架空世界

本阶段新增 120 个宏观事件、60 个个人响应事件，保留 65 个既有人生事件，共 245 个事件资产。其中 125 个个人事件包含 375 个编写选项；系统还会按状态安排休整、借款答复等机会。

## 内容怎样驱动

世界从“澄川诸邦”的新历元年开始。每两年检查一次宏观候选事件，按前提、冷却、是否一次性和权重选出最多一个；没有日期对应的现实历史剧本。四组互斥模式描述供能、治理、贸易、技术组织，20 项指标描述当时的社会与环境状态。

宏观世界使用独立于个人事件的随机流。同一世界种子、同一时间点具有同一条世界历史，选择菜单的操作次数不会偷换宏观随机结果。这一版普通角色通过资源、职业和关系选择应对环境；还没有让角色直接改写国家制度或全球气候的机制。

个人响应事件具有年龄、经历、NPC 与世界前提。一次人生只触发其中合理的一部分。宏观经济、就业、能源、食物等指标同时对成年后的常规收入和生活支出施加有上限的修正。预算以当前状态估算，尚未发生的世界变化仍会改变后续实际结算。

事件旁的“相关时代背景”链接到同领域已经发生的记录。这是背景线索，不宣称某一条新闻是这个人遭遇的唯一原因。世界纪事中的“此前的变化”也只是最近改变相关前提字段的记录。

## 覆盖结构

| 层次 | 内容 | 资产 |
| --- | --- | --- |
| 个人与家庭 | 学习、职业、关系、照护、婚育、退休、回顾 | `life-events.json` |
| 社区与生活处境 | 价格、换岗、住房、求学、无障碍、照护、公共参与、灾害应对等 | `society-events.json` |
| 国家、邦际、行星、前沿 | 20 个领域，各含机会、危机、调适或不同路线 | `world-events.json` |

具体清单见[宏观覆盖](world-coverage-v0.4.md)与[个人响应覆盖](society-content-v0.4.md)。这是可持续扩展的第一批系统内容，不能等同于穷尽现实，也不能把随机模拟当成未来预测。

## 一致性与存档

- 宏观事件只读取受支持的世界字段，效果只通过指标、事实旗标与互斥模式写入。
- 个人选择仍由规则引擎执行资源门槛与交易，不能直接写宏观指标。
- 世界记录保存当时的前提和效果，读取存档时从初始状态重放；记录不能引用未来，当前状态必须与历史相符。
- 已故 NPC 不能作为在世参与者；角色事件与 NPC 时间保持同步。
- v0.2、v0.3 存档保留原有经历、年份、当前选择及人物随机进度。新世界从迁移时刻开始，旧经历不会被重新解释成刚生成的宏观历史。
- 浏览器保留升级前备份。存档仍是本地可编辑数据，不提供防篡改保证。

## 后续怎样管理 AI 生成资产

当前运行不调用模型，因此没有模型等待时间或上下文窗口限制。未来可将模型放在离线编写环节，使用本版契约作为产物格式：

1. 按领域、尺度、人生阶段和前提组合分配内容缺口，形成小批次任务。
2. 生成带稳定编号的候选事件，保留来源、版本、审核状态和依赖字段。
3. 执行结构与类型检查、依赖检查、状态构造测试和多种子运行，列出未触发内容。
4. 人工审查因果合理性、人物身份、物理限制、重复剧情与性格观察是否过度推断。
5. 将通过的批次发布为固定版本；游戏只加载已批准资产。

这些步骤描述下一阶段的资产生产工作流，本版尚未包含生成队列、编辑审核后台或自动发布平台。结构校验能减少错误，不能自动证明世界符合所有物理规律。

## 验证入口

```powershell
python -X utf8 -m unittest discover -s tests -v
python -X utf8 -m game.content_check
python -X utf8 -m game.world_report --seeds 128 --years 82 --output reports/world-v0.4
```

[批量报告](../reports/world-v0.4.md)记录真实出现的领域、事件和发展模式，以及未触发资产。分段推进和 JSON 接续必须与一次推进得到相同结果。内容测试还检查社会响应的年龄、NPC 条件和资源不足时的可行选择。

### 本次验证结果

- 90 项测试全部通过，包括两代旧存档、完整人生、重复算法事故修复、轨道服务关闭／恢复和浏览器安全整数接续。
- 128 个世界种子各推进 82 年，形成 128 条不同事件序列；全部 20 个领域与 12 个模式值出现，触发 105／120 个宏观事件，15 项未在此批出现。详细清单与源文件哈希保存在报告中。
- 浏览器完成新人生到人物志的整局试玩，核对自动保存后的刷新接续、社会响应、时代纪事筛选与背景跳转，并检查 390 像素窄屏布局。
- 世界随机种子采用 52 位整数，避免浏览器 JSON 保存时损失精度。宏观模拟依然可复现。
