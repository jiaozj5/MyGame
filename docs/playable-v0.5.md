# v0.5 · 人间来往

这一版把人物系统扩展到跨世代的 2,000 人名册，接入人生推进、人物查找、档案、消息、主动交往与存档。它是一个可以扩充的社会人物模拟框架，没有穷尽现实中的全部身份或经历。

## 人数的含义

- **容量**：一生中可能进入世界的档案总数，包含四位原有人物和尚未出生的后续世代，不表示开局就有 2,000 位在世邻居。
- **已知 / 直接交往 / 密切**：分别按实际介绍或消息、真实接触和持续相处计算。关注一个人不会自动成为朋友。
- **详细模拟**：默认 200 位重要人物持续保存模拟开始后的完整实际时间线；此外最多可持续关注 200 人。对手、失信者也可以成为关注对象。
- **外围人物**：保留状态、关系和最近六条记录。进入关注范围时保留尚存的旧记录，从此持续记事，不补造已丢弃的早年经历。

人物是否实际进入某个人生，取决于出生时间、年龄、场所、交往安排和已有关系。实际覆盖量见 [批量报告](../reports/population-v0.5.md)，不能用容量替代试玩结果。

## 人物资产

`content/npc-library.json` 提供 128 种职业与生活阶段、32 种身份处境、12 个连续性格轴、12 种动机、姓名词典和 32 类人物互动。具体覆盖见 [NPC 库说明](npc-library-v0.5.md)。

性格轴用于模拟 NPC 的行为倾向，和玩家人物志的八个观察维度分开。贫困、疾病、职业等身份不决定善恶，公开档案也不会把内部倾向分数直接展示为人格诊断。

互动包含互助、合作、冲突、欺骗、剥削、违法侵害及修复。违法行为是虚构世界中的事件与后果，不使用现实司法流程作为承诺。具体伤害和责任需要绑定当事人，例如欺骗后的赔付必须对应原本那一对人物，不能随机找另一个受害者完成“补偿”。

## 时间与一致性

1. 人生向前推进时，先结算世界与原有四位人物，再推进人群。
2. NPC 的出生、学习与工作、收入、健康、迁居、生死和人物间互动按年结算。
3. 行为读取年龄、状态、资源、性格、关系、案件前提与冷却。执行前再次检查，资金不足不能部分扣款。
4. 死亡终止后续本人行动。迁居和临时行动限制影响可用交往，保留已经发生的记录。
5. 人群使用独立随机流；打开档案、筛选人物不会推进世界或改变人生事件随机数。

关系是有方向的稀疏网络，每个人最多六条 NPC 关系边，玩家交往单独记录。它避免把所有人两两相连，却也限制了组织、亲属和社会网络的复杂度；本版并没有完整模拟国家行政、司法、婚姻与继承制度。

原有母亲、父亲、朋友、伴侣仍由人生引擎管理，人群只读取其权威状态。相关资源和关系通过主线事件改变，避免两套数据相互覆盖。

新增人群参与独立生活、NPC 双人事件与玩家的社交行动；现有 125 个主线个人事件仍使用原四位人物，尚未全部改成可绑定任意新人物的剧情。伴侣、亲子和组织成员的完整生成网络也不在本轮实现范围内。

## 实际发生与玩家知情

- 模拟状态保存完整事实；游戏页面只投影已经获知的部分。
- 公开事件可能带来新名字；当事人私下经历通常不直接变成玩家新闻。
- 人物档案展示已知身份、来自相处的印象、消息来源及可见时间线，不展示隐藏倾向或精确财产。
- 尚未出生或尚未获知的人不能通过搜索提前见到；不在场的私事也不会因为“重要人物”身份自动公开。
- 这是单机知情规则，不是防作弊边界：导出的完整 JSON 必须包含隐藏事实以便续玩，手动查看存档能看到它们。

## 游戏操作

在“人间来往”中按姓名、职业、身份或关系范围查找，点人物卡进入档案。可用交往显示资源花费和年度剩余次数。主动交往占用现金或精力，但不消耗关键人生片段；年份仍由主线选择推进。

日常安排有兼顾各处、照应身边人、工作与学业、走进社区和保留私人空间。安排只影响未来实际活动，不立即产生亲近分。每年最多调整三次。

## 存档与性能

存档格式升级为 `1.3.0`，页面版本 `0.5.0`，上一阶段的个人和宏观事件库保持 `0.4.0`。支持 v0.2、v0.3、v0.4 的迁移；保留历史、当前选项和旧随机进度，新增人群从导入年开始模拟。旧存档不补写人际经历。

浏览器使用 IndexedDB 保存增长中的人物档案，旧版 localStorage 存档继续保留。数据库不可用时尝试本地存储，失败会提示导出；导入上限为 20 MB。改变浏览器或端口会切换保存位置。

服务端人口状态按需复制改变的记录，选项预览共享未改变的人群；人物查找与档案接口分页返回公开数据。运行时没有大模型调用或外部网络请求。实测速度与存档体积记录在批量报告中。

## 验证入口

```powershell
python -X utf8 -m unittest discover -s tests -v
python -X utf8 -m game.content_check
python -X utf8 -m game.population_report --seeds 4 --output reports/population-v0.5
```

报告区分理论容量、实际出现、直接交往、密切关系与年度耗时。未触发的模板不算完成可达性验证；当前参数仍需长期试玩调整。

### 本次验证结果

- 完整回归 121 项通过；人口模块最后修复后，42 项人口、内容、HTTP 与集成测试再次通过。
- 4 个种子 × 2 种公开可执行策略，共 8 局都完成至 82 岁，另一次完整重复轨迹一致。
- 实际已知人物 1,202–1,220 人，直接交往 1,137–1,142 人，曾经密切 217–227 人；终局仍在世且密切的为 25–30 人。当前默认安排尚未达到“实际接触 2,000 人”，2,000 仍是跨世代容量。
- 最终紧凑存档约 9.64–9.79 MB；本机人口年度推进平均约 30–31 毫秒，公开视图平均约 5–6 毫秒。接口返回完整存档、网络传输与浏览器写入还会增加实际等待时间。
- 浏览器完成过一整段 82 岁人生，主动帮助的新人物进入人物志；长存档刷新接续成功。人物目录、职业搜索、现金帮助与 390 像素窄屏也已检查。

日志位于 `reports/tests-v0.5.log` 与 `reports/population-tests-v0.5.log`。这些结果反映确定的游戏规则和脚本策略，不是现实人口统计，也不代表真人玩家一定会走出相同的关系数量。
