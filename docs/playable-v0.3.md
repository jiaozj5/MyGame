# 可玩版本 v0.3：日子的压力与选择的回声

本版延续青溪镇的一生，重点是让长期收支、工作节奏和早年经历在后续选择中产生可见影响。运行方式仍是本地 Python 服务与浏览器，无须安装依赖。

## 玩家能看到的变化

- **下一年预估**：根据当前职业、家庭与生活节奏显示收入、支出、结余或缺口，以及精力和压力变化。预估与年度结算共用规则；选择改变安排后，下一年的数字会相应变化。额外事件另行结算。
- **三种工作节奏**：稳健、加紧与放慢。通过工作安排或休整事件选择。加紧可换取收入，长期透支会消耗精力并积累压力；放慢需要接受收入上的取舍。
- **休整机会**：跨年途中身体或压力接近危险线时，先给玩家一个处理当下处境的机会，再继续前往原定的人生片段。休整有冷却，包含不花现金的选择。
- **有来处的事件**：手艺、学习、互助、住房、工作与晚年关系有更多后续。若前序选择确实留下了对应记录，页面会显示可点击的来源；完整故事仍留在人生年表里。

人物志继续描述角色在情境中的行动，不把生存约束当成玩家人格，也不输出心理测量分数。

## 存档升级

本版保存格式为 `1.1.0`，内容与界面版本为 `0.3.0`。可读取上一版 `1.0.0` / `0.2.0` 的存档，保留已经发生的记录、正在等待选择的事件、人物状态与随机进度。新增字段使用明确默认值，后续年度结算采用新规则；历史收支不会重新计算。

浏览器使用新的 v0.3 自动存档位置，原有 v0.2 自动存档仍保留。成功升级前会另存一份原始备份，并在界面提供导出入口。导入失败不会覆盖当前人生。浏览器存储空间不足时应手动导出保存。

旧记录没有新增的因果来源数据时，不补造一条“当年因为……”的解释。未知版本会明确拒绝，不猜测迁移。

## 开发与内容检查

```powershell
python -X utf8 -m unittest discover -s tests -v
python -X utf8 -m game.content_check
python -X utf8 -m game.balance --seeds 6 --output reports/balance-v0.3
```

事件检查器用于发现格式、字段、前序来源和引用问题，不能证明所有分支必然可达。脚本试玩用相同种子集合比较不同家庭与三种明确策略，记录资源、紧缩、救助、休整、锁定选项和事件覆盖。它是调参工具，不预测真实玩家，也不把某个死亡率当作成功标准。

## 本次验证结果

- 65 项自动化测试通过；包含真实旧存档迁移、危机中断与恢复、预测和结算一致、拒绝过期指令、NPC 生死及人物志引用。
- 65 事件、195 选项的静态检查为 0 错误、0 警告。新增 16 个场景有局部前提与反例测试，但不等于全部剧情均已实测到达。
- [54 局对比报告](../reports/balance-v0.3.md)覆盖 45/65 个目录事件，无卡死或非法选择，同种子重跑一致。谨慎、随选策略均到 82 岁；持续透支策略在 43 岁结束，之前每局出现 6 次调整机会。
- 上述固定策略的结局年龄高度一致，经济紧缩也较少，说明当前差异主要来自透支。还不能据此宣称已完成难度平衡或估计真实玩家表现。
- 浏览器验收验证了旧版 JSON 导入、升级提示与备份入口、刷新续接、工作节奏改变预算、因果链接高亮原始记录。实际在 32 岁中断跨年，选择免费调整后继续到原定 34 岁事件。390 像素宽度无横向溢出，测试未发现浏览器脚本错误。

## 仍然保留的边界

时代与经济采用虚构简化规则；82 岁仍是叙事终点。NPC 还没有通用的自主规划系统，事件仍使用已审核的本地内容，尚未接入运行时大模型或批量资产生成平台。难度与叙事节奏仍需实际试玩反馈来调整。
